# Sovraccaricatore temporale

<ItemImage id="iska_utils:temporal_overclocker" />

## A cosa serve

- Si collega ai blocchi vicini per accelerarne tick / lavorazione (comportamento preciso per tipo di blocco supportato).

## Chipset

- Usa oggetti **Chipset del Sovraccaricatore Temporale** per configurare o potenziare la macchina (vedi GUI).

## Potenziamento entropico

- **Slot upgrade** (a sinistra del pulsante Overclock): inserisci un <ItemImage id="iska_utils:entropic_clock" /> **Entropic Clock** per alzare il fattore massimo di overclock. Vedi **Moduli** → **Entropic Clock**.
- **Slot carburante** (a destra del pulsante Overclock): inserisci **Gocce di entropia**; le gocce si convertono in carica entropica interna (percentuale sotto lo slot). L'entropia si consuma accelerando i blocchi collegati quando l'orologio è installato.
