# Catalizzatore di entropia instabile

<ItemImage id="iska_utils:unstable_entropy_catalyst" />

Materiale entropico molto instabile creato sulla <ItemImage id="iska_utils:ancient_tablet" /> **Tavoletta antica**.

## Decadimento

In inventario **decade** nel tempo (circa mezzo minuto di default). Il tooltip mostra una **barra di stabilità**; l'icona cambia col peggioramento.

A decadimento completo l'oggetto **scompare**. Su alcuni server il decadimento può essere letale — leggi l'avviso rosso nel tooltip.

## Usi

- Craft del <ItemImage id="iska_utils:entropic_smithing_template" /> **Modello di forgia entropica** (usalo presto dopo aver creato il catalizzatore).
- Craft della <ItemImage id="iska_utils:entropy_tnt" /> **TNT entropica** con <ItemImage id="iska_utils:entropy_crystal" /> **Cristallo di entropia**.

Per entropia adatta al deposito, preferisci il <ItemImage id="iska_utils:entropy_crystal" /> **Cristallo di entropia**.
