# Flight Nullifier

<ItemImage id="iska_utils:flight_nullifier" />

## What it does

Blocks **player flight** (Survival and Adventure only) inside a cubic **radius** around the block. Same range and Range Module upgrades as the [Ender Nullifier](ender_nullifier.md).

## GUI

Same layout as other nullifiers: **redstone**, **module slot**, **target** (Only mobs / Disabled), range row, and area preview. Target starts on **Only mobs** (effect active for players in Survival/Adventure).

## Tips

- Does not affect Creative or Spectator players.
- See also: [Climbing Nullifier](climbing_nullifier.md), [Ender Nullifier](ender_nullifier.md).
