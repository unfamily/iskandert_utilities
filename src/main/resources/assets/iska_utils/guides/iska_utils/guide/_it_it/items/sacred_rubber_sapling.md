# Arboscello di gomma sacro

<ItemImage id="iska_utils:sacred_rubber_sapling" />

## Crescita

- **Non** cresce con i tick casuali — applica ripetutamente **bonemeal** (**15** utilizzi in totale) per avviare la crescita procedurale.
- La crescita richiede spazio libero per un tronco molto grande e una cupola di foglie.
- Se usi **Agglomerato druidico** sull'arboscello, diventa un albero **mega sacro**, ancora più grande.
