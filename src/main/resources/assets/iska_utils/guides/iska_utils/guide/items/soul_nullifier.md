# Soul Nullifier

<ItemImage id="iska_utils:soul_nullifier" />

## What it does

Block that **prevents Forbidden Arcanus Lost Soul spawns** (normal, corrupt, and enchanted variants) within a cubic **radius** around it on every axis (set in the GUI). Requires **Forbidden Arcanus** to be installed.

## GUI

Right-click the block to open its control GUI. All controls work the same as the [Ender Nullifier](ender_nullifier.md):

- **Range** slider with **-** / **+** buttons.
- **Redstone Mode** button cycling through Ignore (gunpowder), Low, High, Disabled.
- **Shift + Right-click**: toggles manual enable/disable without opening the GUI (action-bar feedback).
- **Show / Hide** area preview.
- **Range Module** slot for increasing the maximum radius.

## Tips

- Same placement behavior as the [Ender Nullifier](ender_nullifier.md).
- Starts **active** (Manual mode, manually enabled) when placed.
