# Soul Nullifier

<ItemImage id="iska_utils:soul_nullifier" />

## What it does

Block that **prevents Forbidden Arcanus Lost Soul spawns** (normal, corrupt, and enchanted variants) within a cubic **radius** around it on every axis. Requires **Forbidden Arcanus** to be installed.

## Controls

- **Right-click**: toggle enabled / disabled (action bar feedback).
- **Shift + right-click**: cycle redstone mode — manual, low, high.
- **Comparator** reads powered state when redstone modes apply.

## Tips

- Same placement and redstone behavior as the [Ender Nullifier](ender_nullifier.md).
- Starts **enabled** when placed.
