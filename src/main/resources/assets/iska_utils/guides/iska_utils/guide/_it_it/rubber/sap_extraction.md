# Estrazione della linfa

<ItemImage id="iska_utils:sap" />

## Estrazione manuale

- Usa un **Estrattore di linfa manuale** su un tronco di gomma pieno per estrarre **Linfa di gomma**.
- L'**Estrattore di linfa elettrico** è la variante a energia (vedi tooltip dell'oggetto per l'uso).

## Automazione

- L'**Estrattore di linfa automatico** può estrarre linfa automaticamente dai tronchi di gomma adiacenti.
