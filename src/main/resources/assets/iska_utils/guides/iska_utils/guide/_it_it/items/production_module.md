# Modulo di produzione

<ItemImage id="iska_utils:production_module" />

Aumenta la produttività o la dimensione del lotto sulle macchine supportate.

| Macchina | Ruolo |
| ------- | ---- |
| **Pattern Crafter** | Più craft eseguiti contemporaneamente. |
| **Entropised Spawner** | Mob extra per ciclo di spawn (per modulo nello stack). |
| **Radiation Scrubber** (se presente) | Passate di depurazione più intense. |
