# Saboteur's Screwdriver

<ItemImage id="iska_utils:saboteur_screwdriver" />

## Use

Right-click a **primed TNT** entity (vanilla or modded) to **defuse** it. The dropped item matches the source: modded primed TNT returns the corresponding TNT block; vanilla primed TNT returns regular TNT.

Also works on **TNT Minecarts**: the explosive is removed, an empty minecart stays on the rails, and TNT is dropped.
