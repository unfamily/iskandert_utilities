# Modulo logico

<ItemImage id="iska_utils:logic_module" />

Espande la capacità sulle macchine supportate.

| Macchina | Ruolo |
| ------- | ---- |
| **Improved Pattern Crafter** | Ogni modulo aggiunge **+1 slot pattern** e **+1 pagina variabili** (**18** chiavi). Max installazione predefinito: **4**. |

Capacità base dell’Improved senza moduli: **6** pattern e **1** pagina variabili (18 chiavi).
