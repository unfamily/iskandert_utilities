# Angel Block

<ItemImage id="iska_utils:angel_block" />

WHAT IT DOES

- Uno **full-sized solid block** che ha bisogno di **no support**: rimane a mezz' aria come un'impalcatura provvisoria.
- **Right-click in the air** (usa l'oggetto senza prendere di mira un altro blocco) per posizionarlo **about two blocks ahead** lungo la tua visuale — ideale per colmare le lacune o stare in piedi mentre costruisci verso l'alto.
- Puoi ancora **place it normally** contro le superfici come qualsiasi altro elemento del blocco.
