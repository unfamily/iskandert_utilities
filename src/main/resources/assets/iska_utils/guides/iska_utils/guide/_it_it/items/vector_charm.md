# Amuleto vettoriale

<ItemImage id="iska_utils:vector_charm" />

## A cosa serve

- Potenzia il movimento sulle **piastre vettoriali** se tenuto in mano, indossato, in Curios (se installato) o in inventario (priorità: mano principale, mano secondaria, Curios, poi inventario).

## Energia

- Buffer RF/FE opzionale e consumo per direzione; vedi il tooltip in gioco per il comportamento esatto.
