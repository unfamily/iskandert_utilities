# Redstone Activator

<ItemImage id="iska_utils:redstone_activator" />

## What it does

The **Redstone Activator** is a handheld item that places a temporary, invisible **signal block** on any surface. The block emits a **full-strength redstone signal** for approximately **3 seconds**, then removes itself automatically.

- **Place**: right-click any solid surface to deploy the signal block. Each use consumes 1 durability.
- **Reclaim**: right-click the signal block you placed to cancel it early and **restore 1 durability**.

The item has **256 durability**, giving up to 256 placements per item. Useful for one-shot redstone triggers, timed pulses, or remote activation without running permanent wiring.
