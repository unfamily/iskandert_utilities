# Piastre vettoriali

<ItemImage id="iska_utils:slow_vect" />

Piastre stile nastro che spingono le entità lungo la faccia di posizionamento. Le icone in inventario mostrano un badge **mobfarm** o **giocatore** per distinguere le due linee.

## Piastre mobfarm

ID senza `player_` (`slow_vect` … `ultra_vect`). Spingono **solo i mob** (non i giocatori).

- **Lenta / Moderata / Veloce / Estrema / Ultra** — tier più alti muovono le entità più rapidamente.

## Piastre giocatore

ID con `player_` (`player_slow_vect` … `player_ultra_vect`). Spingono i **giocatori** allo stesso modo ma ignorano i mob.

## Tier di velocità

Ogni tier di velocità è un blocco diverso. I tier più alti sono upgrade di quelli inferiori.
