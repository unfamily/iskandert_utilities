# Catena di lavorazione

<ItemImage id="iska_utils:rubber_chunk" />

## Dalla linfa alla gomma

- La linfa si lavora in gomma e materiali correlati lungo la progressione della gomma.

## Output comuni

- **Gomma**: ingrediente centrale per strumenti, armature e plastica.
- **Lingotto di plastica**: usato in componenti di tier più alto.
- **Poltiglia verde** / **Slimeball di catrame**: intermedi correlati.
