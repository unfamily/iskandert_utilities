# Pezzo di gomma

<ItemImage id="iska_utils:rubber_chunk" />

## Ottenimento

- Creato dalla **Gomma**.

## Usi

- Fuse in **Lingotto di plastica** (fornace / altoforno).
- Usati quando la gomma viene lavorata ulteriormente in macchine.
