# Linfa di gomma

<ItemImage id="iska_utils:sap" />

## Ottenimento

- Raccogli da **tronchi di gomma pieni** con **Tree Tap** o **Electric Tree Tap**.
- Automatizza con **Rubber Sap Extractor** (vedi **Gomma e lavorazione**).

## Usi

- Fusa in **Gomma** (fornace o macchine compatibili).
- Craftata in **Blocco di linfa di gomma** per deposito.
