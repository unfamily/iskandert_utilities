# Machine modules

<ItemImage id="iska_utils:logic_module" />

Overview of **installable modules** used by machines in Iskandert's Utilities. Vector-speed modules are also crafting parts for **Vector Charm** (see **Acceleration modules**).

## Range Module

<ItemImage id="iska_utils:range_module" />

Expands a machine’s working area or radius.

| Machine | Role |
| ------- | ---- |
| **Modular Fan** | Raises max reach on all axes. |
| **Collecting Crate** | Raises max collection extents. |
| **Ender / Wander / Soul Nullifier** | Raises max protection radius. |
| **Blazing Altar** | Raises chunk coverage radius. |

## Ghost Module

<ItemImage id="iska_utils:ghost_module" />

| Machine | Role |
| ------- | ---- |
| **Modular Fan** | Lets airflow interact through solid blocks. |

Higher tiers mean stronger speed effect. Also used as Vector Charm craft ingredients (**Acceleration modules**).

| Machine | Role |
| ------- | ---- |
| **Modular Fan** | Speeds fan thrust. |
| **Pattern Crafter** | Shortens crafting time. |

## Logic Module

<ItemImage id="iska_utils:logic_module" />

| Machine | Role |
| ------- | ---- |
| **Pattern Crafter** | Unlocks more variable keys / pattern capacity. |

## Production Module

<ItemImage id="iska_utils:production_module" />

| Machine | Role |
| ------- | ---- |
| **Pattern Crafter** | More crafts running at once. |
| **Entropised Spawner** | Extra mobs per spawn cycle (per module in the stack). |
| **Radiation Scrubber** (when present) | Stronger scrub passes. |

## Capacitor Module

<ItemImage id="iska_utils:capacitor_module" />

| Machine | Role |
| ------- | ---- |
| **Radiation Scrubber** (when present) | Energy / capacity related upgrade for scrubbing. |

## Mob Reaper modules

| Module | Role |
| ------ | ---- |
| **Normal damage** | Stackable damage bonus. |
| **Lethal damage** | Very high fixed damage (replaces normal). |
| **Enchant** | Holds a weapon; enchantments apply to attacks. |
| **Beheading** | Extra skull drop chance. |
| **Luck** | Luck for loot rolls. |
| **Experience** | Bonus XP multiplier on kills. |
