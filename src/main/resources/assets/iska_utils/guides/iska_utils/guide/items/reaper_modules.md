# Mob Reaper modules

Installable upgrades for the **Mob Reaper**. Use **one damage module type** at a time: **Normal** (stackable) **or** **Lethal** (single). The other upgrades stack independently.

| Module | Role |
| ------ | ---- |
| **Normal damage** | Stackable damage bonus. |
| **Lethal damage** | Very high fixed damage (replaces normal). |
| **Enchant** | Holds a weapon; enchantments apply to attacks. |
| **Beheading** | Extra skull drop chance. |
| **Luck** | Luck for loot rolls. |
| **Experience** | Bonus XP multiplier on kills. |
