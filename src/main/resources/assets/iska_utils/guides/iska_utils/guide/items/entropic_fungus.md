# Entropic Fungus

<ItemImage id="iska_utils:entropic_fungus" />

## What it is

A mushroom-like plant tied to the entropy progression. It can be planted on **any sturdy top face**. Natural worldgen still only appears on **stone-like** surfaces in the **Overworld**, **Nether**, and **End**.

**Worldgen** (config `worldgen.001_generate_entropic_fungus`, default **true**):

- **Overworld** — common cave **patches** of **1–3** from **Y -64 to 72** (deep + upper)
- **Nether** — same as Overworld; **Warped Forest** denser
- **End** — very dense patches on end stone

## Drops

- Breaking the block (including with shears) yields **1** <ItemImage id="iska_utils:entropic_fungus" /> **Entropic Fungus** when the block is not destroyed by explosion.
- Place in a <ItemImage id="iska_utils:factory" /> **Factory** to convert it into **1** <ItemImage id="iska_utils:drop_of_entropy" /> **Drop of Entropy**.

## Optional: Botany Pots

When **Botany Pots** is installed, **Entropic Fungus** can be grown in a pot using the mod’s crop recipe (long grow time; loot matches the block drop table).
