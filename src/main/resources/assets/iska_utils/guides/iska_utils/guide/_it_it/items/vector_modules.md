# Moduli vector (accelerazione)

<ItemImage id="iska_utils:slow_module" />

## Uso

- Componenti da crafting per **Amuleto vettoriale** e equip vector correlato (tier più alti per amuleti di tier superiori).
- **Upgrade velocità** quando installati in macchine che li accettano:
  - **Modular Fan** — spinta più forte.
  - **Pattern Crafter** — tempo di crafting più breve.
- **Non** si installano nelle piastre vettoriali.

Tier più alti = effetto velocità più forte.
