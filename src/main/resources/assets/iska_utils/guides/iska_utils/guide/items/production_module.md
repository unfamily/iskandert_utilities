# Production Module

<ItemImage id="iska_utils:production_module" />

Increases throughput or batch size on supported machines.

| Machine | Role |
| ------- | ---- |
| **Pattern Crafter** | More crafts running at once. |
| **Entropised Spawner** | Extra mobs per spawn cycle (per module in the stack). |
| **Radiation Scrubber** (when present) | Stronger scrub passes. |
