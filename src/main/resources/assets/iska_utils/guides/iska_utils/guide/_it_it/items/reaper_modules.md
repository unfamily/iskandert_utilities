# Moduli per la Mietitrice di mob

Upgrade installabili per la **Mietitrice di mob**. Usa **un solo tipo di modulo danno** alla volta: **Normale** (impilabile) **oppure** **Letale** (singolo). Gli altri upgrade si impilano indipendentemente.

| Modulo | Ruolo |
| ------ | ---- |
| **Danno normale** | Bonus danno impilabile. |
| **Danno letale** | Danno fisso molto alto (sostituisce il normale). |
| **Enchant** | Contiene un'arma; gli enchantment si applicano agli attacchi. |
| **Decapitazione** | Probabilità extra di drop di teschi. |
| **Fortuna** | Fortuna per i tiri di loot. |
| **Esperienza** | Moltiplicatore di XP bonus alle uccisioni. |
