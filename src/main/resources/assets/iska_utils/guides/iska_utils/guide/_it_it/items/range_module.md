# Modulo di portata

<ItemImage id="iska_utils:range_module" />

Espande l'area operativa o il raggio di una macchina.

| Macchina | Ruolo |
| ------- | ---- |
| **Modular Fan** | Aumenta la portata massima su tutti gli assi. |
| **Collecting Crate** | Aumenta le estensioni massime di raccolta. |
| **Ender / Wander / Soul Nullifier** | Aumenta il raggio massimo di protezione. |
| **Blazing Altar** | Aumenta il raggio di copertura dei chunk. |
