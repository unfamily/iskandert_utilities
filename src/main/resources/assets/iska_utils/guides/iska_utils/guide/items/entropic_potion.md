# Entropic Potion

## Effects

Drinking applies both:

- **Entropic Empowerment** (player variant) — same combat bonuses as the mob empowerment marker
- **Entropic Decay** — harmful; lasts **twice** as long as the empowerment on that bottle

While Decay is active, expired **harmful** effects and mod **curses** (such as Curse of Pain) have a **30%** chance to return for a short random time (10–30 s at I, +10 s per level on both ends). Decay never re-rolls itself.

If a player somehow has Empowerment without Decay, Decay is reapplied at **2×** the remaining empowerment duration.

Entities with these effects emit **entropic flame** particles (Decay emits fewer).
