# Range Module

<ItemImage id="iska_utils:range_module" />

Expands a machine’s working area or radius.

| Machine | Role |
| ------- | ---- |
| **Modular Fan** | Raises max reach on all axes. |
| **Collecting Crate** | Raises max collection extents. |
| **Ender / Wander / Soul Nullifier** | Raises max protection radius. |
| **Blazing Altar** | Raises chunk coverage radius. |
